FIREWORKS AI

La tua chiave API

La chiave viene salvata nel localStorage di questo browser e inviata solo a Fireworks per l’analisi. È separata dai dati delle squadre. Gli script di questo sito e delle altre app sullo stesso dominio possono leggerla: usa un dispositivo fidato e una chiave dedicata.

Modello: DeepSeek V4.1 Flash. La ricerca web deve essere abilitata sul tuo account Fireworks. L’analisi richiede Internet e utilizza il tuo credito.

NUOVA SQUADRA

Dai un nome alla tua squadra

I ruoli dei giocatori seguiranno il listone scelto. Partirai con una rosa vuota.

IMPORTA UNA SQUADRA

La tua rosa, da un file

Scegli un file .txt e controlla l’anteprima prima di aggiungere la squadra. Il file viene letto solo su questo dispositivo, senza caricarlo online.

Come preparare il file
Squadra: Atletico Federicao

P - Maignan (Milan)
D - Akanji (Inter)
C - Barella (Inter)
A - Lucca (Napoli)

Una riga per giocatore: ruolo P, D, C o A, trattino, nome e club tra parentesi. Testo semplice UTF-8, massimo 40 giocatori e 64 KB. Non serve scegliere un listone.

Aggiungi dal listone

Ruoli classici P/D/C/A. Le liste sono quelle dei file forniti, senza aggiornamento automatico. Quotazione e ruolo non sono previsioni di rendimento.

Quale listone vuoi usare?

La tua rosa attuale verrà conservata. La scelta si applica ai giocatori che aggiungerai dal listone.

FantaApp sul tuo iPhone

  1. Apri questo sito in Safari.
  2. Apri il menu Condividi e scegli “Aggiungi alla schermata Home”.
  3. Se disponibile, lascia attivo “Apri come app web” e tocca “Aggiungi”.

Apri FantaApp dall’icona almeno una volta con Internet. Attendi “Disponibile offline” prima di usarla senza connessione.

I dati salvati sono locali. Safari e l’app installata possono avere archivi separati: usa l’icona Home per gestire le squadre.
